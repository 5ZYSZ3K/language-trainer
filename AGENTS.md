## Agent skills

### Issue tracker

GitHub Issues on the public repo 5ZYSZ3K/language-trainer, via `gh`. There are no PRs: work lands as Conventional
Commits on `main`, checked locally because there is no CI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default label names (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), plus
GitHub's `bug` and `enhancement` as categories. Live scrapes, publishing, licensing and judging Czech are
`ready-for-human`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root holds the domain language. The README holds the spec and the decisions
(there is no `docs/adr/` yet). See `docs/agents/domain.md`.
